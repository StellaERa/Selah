# Selah Frontend

The Selah frontend is a Next.js application for Bible study, mentorship, study groups, and citations-only Scripture study.

## Planned screens

- Bible canon and translation selection
- Cited study assistant
- Courses and mentor listings
- Study groups and transparent fund ledgers
- SEP-10 wallet authentication with Freighter
- Community review and certificate verification

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- Stellar/Freighter wallet integration

## Getting started

Requirements: Node.js 20+ and npm.

```bash
cd Frontend
npm install
npm run dev
```

Open `http://localhost:3000`. Use Stellar Testnet while developing wallet and payment flows.

## Commands

```bash
npm run dev
npm run build
npm run start
npm run lint
```
